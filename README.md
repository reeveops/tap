# reeveops / tap

Homebrew tap for [reeve](https://github.com/reeveops/reeve) — the PR-native,
self-hosted GitOps orchestrator for Pulumi, Terraform, and OpenTofu.

## Install

```bash
brew install reeveops/tap/reeve
```

Or add the tap first (same thing, two steps):

```bash
brew tap reeveops/tap
brew install reeve
```

## What you get

The `reeve` binary for your platform:

| OS    | Intel (`amd64`) | Apple Silicon (`arm64`) |
| ----- | --------------- | ----------------------- |
| macOS | ✅               | ✅                       |
| Linux | ✅               | ✅                       |

Binaries are pulled from [reeve releases](https://github.com/reeveops/reeve/releases)
and SHA-256 verified against the release checksums (which are
[cosign-signed](https://github.com/reeveops/reeve/blob/master/SECURITY.md) by
the release pipeline).

## Update

```bash
brew upgrade reeve
```

## Uninstall

```bash
brew uninstall reeve
brew untap reeveops/tap
```

## How this tap is maintained

The `Casks/reeve.rb` cask is **auto-generated by GoReleaser** on every
[reeve release](https://github.com/reeveops/reeve/releases). Do not edit it by
hand — the next release overwrites it. The `livecheck` stanza is set to skip
because versions are pushed, not discovered.
